# 🎨 ASCII Photo Studio — Сверхвысокое разрешение в терминале

Преобразование любых фотографий в детальный арт из **букв, цифр и символов** прямо в терминале с поддержкой 24-битного цвета (TrueColor RGB).

---

## 🚀 Как запускать

1. **Двойной клик по [run.bat](file:///C:/Users/KAORU/Desktop/sam/run.bat)** — откроется окно студии.
2. **Или перетащите фото прямо на `run.bat`** мышкой в проводнике — программа сразу запустится и отрисует его!

---

## 📸 Как передавать фото внутри программы

1. **Drag & Drop:** Перетащите файл картинки из любой папки прямо в окно терминала и нажмите `Enter`. Программа **мгновенно** отрисует его в высоком разрешении!
2. **Клавиша `F`:** Открывает стандартное окно проводника Windows для выбора фото.
3. **Клавиша `C`:** Вставляет фото прямо из буфера обмена (если вы скопировали картинку в браузере, Telegram или сделали скриншот через `Win + Shift + S`).

---

## 🎮 Управление после отрисовки (окно не закрывается!)

После того как фото нарисовано, окно остается открытым:
- **`[W]`** — Изменить разрешение/ширину (по умолчанию по ширине окна, можно поставить 160, 240, 320+ символов).
- **`[1]`** — Цветной ASCII (буквы, цифры и символы TrueColor).
- **`[2]`** — Символы + Фоновый цвет ячейки (максимальная сочность).
- **`[3]`** — Черно-белый / монохромный ASCII.
- **`[4]`** — Half-Block режим (удвоенное вертикальное разрешение полублоками `▀`).
- **`[H]`** — Открыть HTML-файл в браузере (там можно бесконечно зумить колесиком мыши).
- **`[Q]`** — Выйти из программы.

---

## 🔍 Секрет фотографической четкости в терминале

> В Windows Terminal / PowerShell:
> Зажмите **`Ctrl`** и покрутите **колесико мыши вниз** (или нажимайте `Ctrl` + `-`).
> Размер шрифта уменьшится, и арт превратится в настоящее четкое фото!
