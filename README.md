# 🎨 ASCII Photo & Video Studio — Сверхвысокое разрешение, 60+ FPS и звук!

Преобразование любых фотографий и воспроизведение **видео со звуком** в терминале из **букв, цифр и символов** с поддержкой 24-битного цвета (TrueColor RGB) и максимальным FPS!

   ```powershell
   py ascii_photo.py

   # Воспроизведение конкретного видео напрямую:
   py ascii_video.py sample_video_with_audio.mp4 160 1
   ```

## 🎬 Воспроизведение видео со звуком (Высокое разрешение и 60+ FPS)

Программа поддерживает форматы видео: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.gif`, `.wmv` и др.

### 🔊 Воспроизведение и синхронизация звука:
- **Встроенный аудиодекодер (PyAV + miniaudio):** Воспроизводит звук любого формата (AAC, MP3, Vorbis, Opus, FLAC, PCM и др.) с аппаратным выводом через Windows WASAPI.
- **Отказоустойчивость:** Если у видео нет аудиодорожки или отсутствует аудиоустройство, видео продолжает плавно играть без звука, без ошибок и без вылетов!
- **Синхронизация:** При паузе (`Space`) звук мгновенно встает на паузу, при возобновлении — продолжает играть с нужной миллисекунды, при перемотке (`R`) — возвращается в начало.
- **Управление звуком:** Клавиша **`[M]`** позволяет мгновенно заглушить или включить звук (Mute/Unmute) прямо во время воспроизведения.

### ⚡ Оптимизации производительности:
- **Zero-Flicker (Без мерцания):** Кадры выводятся через перемещение курсора в начало экрана (`\x1b[H`) и скрытие курсора (`\x1b[?25l`), без медленной очистки экрана.
- **Color Run-Length Encoding:** Квантование и сжатие повторяющихся ANSI-кодов уменьшают размер буфера в 2–3 раза, обеспечивая стабильные 30–60 FPS.
- **Умная синхронизация времени:** Отслеживание реального времени с микросекундной задержкой и автоматическим пропуском отстающих кадров, чтобы видео не замедлялось.

### 🎮 Управление во время воспроизведения видео:
- **`[Пробел]`** — Пауза / Возобновление (видео и звук).
- **`[M]`** — Включить / Выключить звук (Mute / Unmute).
- **`[1]`** — Режим: Цветной TrueColor (буквы, цифры и символы).
- **`[2]`** — Режим: Символы + затемненный фон ячейки (максимальная сочность цвета).
- **`[3]`** — Режим: Черно-белый / монохромный ASCII.
- **`[4]`** — Режим: Ultra Half-Block (удвоенное вертикальное разрешение полублоками `▀`).
- **`[+]` / `[-]`** — Увеличить / уменьшить разрешение (ширину) на лету.
- **`[R]`** — Перемотка видео и аудио в начало.
- **`[F]`** — Включить / выключить счетчик реального FPS и статусную строку.
- **`[Q]` / `[Esc]`** — Выход из режима воспроизведения в главное меню.

## 📸 Работа с фото

1. **Drag & Drop:** Перетащите файл картинки (`.jpg`, `.png`, `.webp`, `.bmp` и т.д.) прямо в окно терминала и нажмите `Enter`.
2. **Клавиша `F`:** Открывает стандартное окно проводника Windows для выбора фото или видео.
3. **Клавиша `C`:** Вставляет фото прямо из буфера обмена (если вы скопировали картинку через `Ctrl+C` или `Win + Shift + S`).
4. **Масштабирование:** Клавиши `[+]` и `[-]` или выбор пресетов по клавише `[W]` (160, 200, 260, 340 символов).
5. **HTML-вьювер:** Каждое фото автоматически сохраняется в HTML-файл с поддержкой зума колесиком мыши (`Ctrl + Wheel`).
